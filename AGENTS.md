# AGENTS

This is a research codebase for SNF-MV (Structural News Forensics with Multi-View decomposition and reasoning).

Current goals:
1. bootstrap a clean project scaffold
2. target Weibo first
3. preserve legacy code under src/legacy
4. keep changes minimal and high-confidence
5. do not refactor legacy code unless explicitly asked

Coding guidelines:
- prefer readable code
- avoid unnecessary abstractions
- add tests when feasible
- keep the repo easy for incremental experimentation
